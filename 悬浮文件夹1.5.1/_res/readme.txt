悬浮文件夹 · 使用说明
======================

一、这是什么
把你的一个文件夹“挂在桌面上”的小工具：常驻桌面的一张小卡片，直接列出文件夹里的文件，
双击就能打开，拖进去就能存，不用每次去翻资源管理器。体积小，不装运行库，绿色单文件。

二、安装与卸载
1) 双击「悬浮文件夹安装包.exe」，点“开始安装”。装到当前用户目录，不需要管理员权限：
   C:\Users\<你的用户名>\AppData\Local\Programs\悬浮文件夹
2) 安装时可以勾选：创建桌面快捷方式、开机自启动（后者也可以装完在设置面板里自己开关）。
3) 卸载：开始菜单 → 设置 → 应用 → 已安装的应用 → 找到「悬浮文件夹」→ 卸载；
   或者直接运行安装目录里的「卸载悬浮文件夹.exe」。
   卸载只删程序本体和快捷方式，不删你放进文件夹里的文件。

三、第一次启动
双击桌面上的「悬浮文件夹」。第一次运行会自动建一个默认文件夹：
   C:\Users\<你的用户名>\Documents\悬浮文件夹
并放一个说明文件进去。想换成你自己的文件夹，点右上角“⋯”→ 切换文件夹，选一个目录即可。

四、界面说明
· 顶部左边是文件夹图标和标题：显示当前文件夹名和条目数量（如 “_demo · 12”）。
· 顶部右边四个按钮：＋ 添加文件、⋯ 更多操作、▾ 收起成小图标、✕ 关闭。
· 下面就是文件列表；切到小图标方式时是网格排列（图标取文件真实的系统图标）。

五、常用操作
· 双击：打开文件或进入子文件夹。
· 右键：弹出的是资源管理器里一模一样的原生菜单——打开、打开方式、发送到、剪切、复制、创建快捷方式、
  删除、重命名、属性；装了压缩软件还会有「添加到压缩文件」，装了杀毒软件也会有对应项，
  和你在这个真实文件夹里右击完全一致（这些操作都由系统自己执行）。
· 键盘：Ctrl+C 复制、Ctrl+X 剪切、Ctrl+V 粘贴（粘贴进来时按“复制”还是“移动”，取决你之前按的是复制还是剪切）、
  上下键选择、Enter 打开、Delete 删除（进回收站）、F2 重命名、F5 刷新。
· 把文件或文件夹直接拖到卡片上：是“移动（剪切）”，不是复制——文件会从原来的位置挪进当前文件夹，
  重名会自动加 “ (2)”。想留一份副本，请先在原位置自己复制一份。
· 反过来也行：把卡片里的文件拖到资源管理器、桌面或别的程序里，同样是移动（剪切）。
· ＋ 按钮：从别处挑选文件添加进来。

六、“⋯”菜单里的项目
· 设置…：打开设置面板（外观、圆角、显示方式、排序、开机自启动、置顶）
· 打开文件夹：用资源管理器打开当前文件夹
· 切换文件夹…：换一个要显示的目录
· 添加文件…：挑选文件复制进来
· 新建文件夹 / 新建文本文件：直接在当前文件夹里创建
· 显示方式：在「列表」和「小图标」之间切换（小图标用的是文件真实的系统图标）
· 排序：按名称 / 修改时间 / 大小
· 开机自启动：勾选后，下次开机会自动出现（写的是当前用户的启动项，随时可以取消）
· 窗口置顶：默认是关闭的——只在桌面正常显示，打开别的应用会被正常遮挡；
  想让它在所有窗口之上，勾上这个即可（状态会被记住）
· 收起成小图标：缩成小文件夹图标，鼠标点一下就展开
· 退出悬浮文件夹
菜单里的勾选项前面有 ✓，表示当前是开着的。

七、设置面板（外观设置）
“⋯”菜单第一项就是「设置…」，点开是一个和卡片同色系的面板（深色主题是深色、浅色主题是白色玻璃），
改完立刻生效：
· 背景图片：一排 5 个缩略图——纯色 + 雾霾蓝 / 暖杏米 / 薄荷青绿 / 薰衣草紫粉，点一下就切换，
  选中的格子有金色描边和 ✓。选图片后，文字和图标颜色会按这张图的深浅自动配成浅色或深色。
· 背景颜色：12 个预设，两排各 6 个，彼此差别很明显：
    深色一排：石墨 / 曜黑 / 午夜蓝 / 松绿 / 酒红 / 咖褐
    浅色一排：雾白 / 米白 / 淡蓝 / 淡绿 / 淡粉 / 蓝灰
  也可以点「自定义颜色…」自己调。选浅色时，文字、线条、徽标底色会自动转成深色，不用手动调。
  （背景图片选“纯色”时，这里选的颜色才生效；选了某张图片，底色会取这张图的基准色。）
· 圆角：小 / 中 / 大 三档，窗口、菜单、设置面板的圆角会一起跟着变；圆角是按抗锯齿曲线画的，
  不再用像素级裁剪，边缘是平滑的弧线而不是台阶。
· 显示方式 / 排序 / 开机自启动 / 窗口置顶：同“⋯”菜单里的开关。
· 左下角「恢复默认」：石墨色 + 中等圆角。
· 换背景色时，卡片、“⋯”下拉菜单、设置面板三处会同时换成同一套颜色（深浅、边框、悬停色都一致），
  所以三处看起来是同一个风格。
外观参数都会写进配置（bg / radius / bgimg），下次启动保持上次的样子。

八、调整大小与位置
· 拖动窗口顶部标题区域可以移动；靠近屏幕边缘会自动贴边。
· 拖动右下角的三道斜纹可以改大小：拖的时候顶部那一排按钮（＋ ⋯ ▾ ✕）和手柄会一直贴着窗口边缘走，
  只有列表内容等松手后一次性重排，所以既不会闪，也不会出现按钮突然消失又冒出来；
  改成任意尺寸后，圆角、列数、滚动条、字号都会跟着变。
· 手柄会随圆角大小自动往里收，圆角调大时也不会露出方角。
· 位置、大小、当前文件夹、排序、显示方式、背景色、圆角、是否置顶，都会自动记住。

九、关于背景的原理
卡片背景不再去抓取身后的窗口，而是用程序内置的纯色或磨砂渐变图片铺满圆角卡片，
最上面才画文字、图标，所以字和图标永远是清晰不透明的。
· 不勾「窗口置顶」时，卡片就在桌面上，效果最自然。
· 按 Win+D 显示桌面时，卡片会一直留在桌面上，不会跟着别的窗口一起被最小化；
  这时点开任何一个应用，它照常会被那个应用窗口遮挡（它只在桌面上常驻，并不压住别人的窗口）。

十、文件与配置都在哪
· 你的文件：默认在「我的文档\悬浮文件夹」（可以换成任何目录）。
· 程序配置：C:\Users\<你的用户名>\AppData\Roaming\FloatingFolder\config.ini
  删掉这个文件，程序就会回到默认状态（默认文件夹、列表方式、石墨背景、不置顶）。

十一、常见问题
· 打开别的应用后它还在最前面？→ 在“⋯”菜单里取消勾选「窗口置顶」，或在设置面板关掉置顶开关。
· 找不到窗口了？→ 关掉程序重新打开，位置会自动纠正回屏幕内。
· 列表里没变化？→ 文件夹内改动会在 1 秒内自动刷新，也可以按 F5。
· Ctrl+V 粘贴没反应？→ 先确认剪贴板里确实有文件：在卡片里选中一行按 Ctrl+C 或 Ctrl+X 就能装进去；
  从资源管理器复制/剪切过来的文件，在卡片里 Ctrl+V 也会进来（复制过来的是复制，剪切过来的是移动）。
· 拖进来以后原位置的文件不见了？→ 拖拽是移动（剪切），文件只是被挪进了卡片对应的文件夹，
  不是丢了；想保留原位置的副本，拖之前自己先复制一份。
· 不想要开机自启动？→ 设置面板里把「开机自启动」关掉。
· 想彻底清干净？→ 卸载后如果还想删配置，删掉上面那个 AppData\Roaming\FloatingFolder 文件夹即可。
